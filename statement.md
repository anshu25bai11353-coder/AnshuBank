# AnshuBank — Project Statement

## Problem Statement
Small banking simulations often demonstrate deposits and withdrawals but do not show how transaction integrity, fraud monitoring, persistence, reporting and concurrency work together. AnshuBank addresses this by providing a local command-line banking simulation with customer operations and an administrative fraud-monitoring workflow.

## Scope
The project covers customer/account management, deposits, withdrawals, atomic transfers, rule-based fraud analysis, alerts, reports, database CRUD, JDBC transaction handling, JPA/JPQL demonstrations and concurrent transaction processing. It is an educational simulator and does not connect to real financial systems.

## Target Users
- Students/evaluators studying Java application design.
- Customers using the simulated banking functions.
- Administrators monitoring simulated banking activity.

## High-Level Features
- Customer and admin authentication
- Savings/current accounts
- Deposit, withdrawal and transfer
- Fraud risk scoring and alerts
- Concurrent transaction processing
- H2 persistence using JDBC and JPA
- Statements and administrative reports
